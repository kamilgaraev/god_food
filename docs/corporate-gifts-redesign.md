# Корпоративные подарки

Страница `/corporate-gifts/` сверстана по Figma `9nW76FWjngfPqFIFZuYBGh`, основной фрейм `1:2`, окно набора `112:114`. Общие шапка и подвал остаются компонентами сайта. Отдельного мобильного фрейма в предоставленном макете нет; адаптив проверяется на 320–2560 px.

## Настройки

- **Настройки → Формы заявок → Корпоративные подарки**: получатель, включённые и обязательные контактные поля, дополнительные поля и варианты списков. По умолчанию добавлены компания, тираж, повод, срочность и набор. Заявки сохраняются в существующем разделе заявок; настройки главной и сотрудничества независимы.
- **Контент сайта → Общие блоки → Корпоративные подарки → Ссылка на каталог PDF**: URL файла, например из медиатеки. Заполненная ссылка выводит «Скачать каталог PDF», пустая — «Запросить каталог» с переходом к форме.
- **Фотоподборки → Корпоративные подарки**: сохранённые фотографии и отключение блока продолжают учитываться. Пока настроек нет, используются фотографии макета. Отзывы берутся из существующих опубликованных отзывов сайта.

Кнопка «Заказать» в окне набора заполняет дополнительное поле с ключом `gift`. Если администратор удалил его, выбор добавляется в включённое поле комментария. В макете четыре миниатюры одного и того же изображения; окно показывает единственное доступное изображение каждого набора без дублирования миниатюр.

Изображения `*-original.jpg/png` в `wp-content/themes/theobroma/assets/images/corporate/` — исходные байты растров из Figma без уменьшения и повторного сжатия. Фотоподборка показывает оригиналы медиатеки, а не размер `large`. Начальная подборка соответствует двум кадрам макета `8:658`: шоколад и упаковка на постаменте.

После первой выкладки выполнить `php /opt/theobroma-scripts/sync-corporate-figma-gallery.php` внутри контейнера WordPress. Скрипт импортирует оригиналы 2731×4096 и 2723×4096, сохраняет резервную копию настроек в опции `theobroma_corporate_figma_gallery_20260917_backup` и меняет только корпоративную подборку. Повторный запуск сохраняет последующие изменения администратора.

Лента преимуществ непрерывно движется, при наведении и фокусе останавливается; кнопка справа переключает постоянную паузу. При системном ограничении анимации выводится статический текст. Контактная карточка использует размер шрифта 1.5rem (1.375rem на мобильных) и масштабируется вместе с базовым размером сайта.

Тексты и начальные цены наборов взяты из макета; скрытые ответы FAQ дополнены осторожными формулировками с уточнением условий у менеджера.

## Проверки

```text
npm run test:corporate-redesign
php wp-content/plugins/theobroma-contact-forms/tests/run.php
php scripts/verify-lead-form-simplification.spec.php
php scripts/verify-contact-request-validation.spec.php
docker compose exec -T wordpress php /opt/theobroma-scripts/verify-corporate-form-integration.php
```

Интеграционная проверка использует временные WordPress-фильтры, не изменяет базу и не отправляет письма. Браузерная проверка также не отправляет заявки; для проверки выложенной страницы задайте `CORPORATE_BASE_URL`.
