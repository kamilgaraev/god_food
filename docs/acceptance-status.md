# Матрица приёмки Theobroma

Проверено локально 6 августа 2026 года на `http://localhost:8080`.

| Требование | Статус и доказательство |
| --- | --- |
| WordPress + WooCommerce, контент и SEO | Пройден `scripts/verify-wordpress.php`: 27 товаров, 4 статьи, рецепты, юридические страницы, корпоративные подарки и SEO-описания. |
| Адаптивность | Публичные страницы, товар/корзина и кабинет проверены браузером на 390/768/1440 px; header — также на 1920/2048/2560/3840 px. Overflow не найден. |
| Товарная и корзинная модалки | Из каталога открывается товар, товар добавляется в корзину, корзина открывается и закрывается на 390/768/1440 px. |
| Личный кабинет и бонусы | Проверены вход, навигация (не менее 6 пунктов), заказы, бонусы, адреса и профиль на 390/768/1440 px. |
| Медиа и кросс-продажи | 4 статьи содержат валидные связанные WooCommerce-товары; блок открывает существующую товарную модалку. |
| Корпоративные подарки | Реализована страница `/corporate-gifts/`, B2B-форма, сохранение заявки и уведомление через `wp_mail`. |
| SEO | Работают `robots.txt`, `wp-sitemap.xml`, мета-теги/OG и JSON-LD из SEO-плагина; SEO smoke-тест пройден. |
| Антиспам | Все контактные формы используют nonce, honeypot и серверную задержку минимум 3 секунды. |
| Ozon Доставка | **Не готово к live-приёмке:** `0/27` внешних SKU, нет merchant approval/token и подтверждённого live-теста. Реализация корректно не предлагает доставку до выполнения этих условий. |
| СДЭК | **Не готово к live-приёмке:** необходимы договор, Client ID/secret, данные отправителя, тарифы и тестовый заказ. |
| ЮKassa / 54-ФЗ | **Не готово к live-приёмке:** нужны demo/live Shop ID и secret key, настройка уведомлений и согласованная схема фискализации. |
| Облачная 1С | **Не готово к реализации/приёмке:** отсутствуют согласованные протокол, доступы, формат обмена и правила бонусов/скидок. |
| Яндекс.Метрика и серверное кэширование | **Не настроены:** требуется ID счётчика и решение на хостинге/плагин, согласованное с исключениями WooCommerce. |

AI-конструктор намеренно не реализован: по ТЗ он выделен в отдельный этап, а текущая задача прямо исключает его из реализации.
