# Безопасные направления обмена Theobroma 1C

## Назначение

Расширить настройки реальными независимыми направлениями обмена: экспорт оплаченных заказов WooCommerce в 1С, импорт статусов существующих заказов, импорт остатков и цен для существующих товаров. Все входящие направления выключены по умолчанию.

## Безопасные границы

- Импорт не создаёт и не удаляет товары, вариации, категории или заказы.
- Не изменяются название, описание, изображения, основной WooCommerce SKU, налоги, публикация и структура каталога.
- Товар обновляется только при единственном совпадении по GUID 1С, артикулу 1С, SKU, артикулу клиента, Ozon ID/SKU или EAN. Неоднозначные и неизвестные позиции пропускаются и журналируются.
- Заказ обновляется только по ID формата `WC-ORDER-<id>` и только в разрешённый статус WooCommerce. Суммы, покупатель и состав заказа не меняются.
- Каждый входящий канал имеет отдельный переключатель. Главный переключатель и авторизация обязательны.
- XML ограничен 10 МБ, принимаются только XML-файлы с безопасным basename, DTD/ENTITY запрещены, внешняя сеть при разборе отключена.
- Временные файлы изолированы по HMAC-сессии, записываются с блокировкой и удаляются после обработки.

## Протокол

Существующий `type=sale` сохраняет `query/success` для экспорта заказов. Для входящих данных поддерживаются стандартные режимы 1С `checkauth`, `init`, `file`, `import`: `type=catalog` принимает CommerceML-предложения с ценами/остатками, `type=sale` принимает документы со статусами заказов.

## Интерфейс

Карточка настроек получает раздел «Направления обмена» с четырьмя независимыми переключателями и пояснением безопасности. Диагностика показывает состояние каждого направления. Журнал фиксирует количество применённых, пропущенных и ошибочных записей без XML и персональных данных.
