# Единый интерфейс страниц заказа WooCommerce

## Цель

Привести служебные страницы WooCommerce к визуальному языку Theobroma без изменения бизнес-логики заказов и без хрупкого полного копирования всех шаблонов WooCommerce.

## Охват

- успешное оформление заказа (`order-received`);
- просмотр одного заказа в личном кабинете;
- список заказов в личном кабинете;
- страница оплаты существующего заказа;
- общие блоки состава заказа, итогов, статуса, способа оплаты и адресов.

## Визуальное направление

Используются только существующие токены и приёмы темы: фон `#fcf9f7`, мягкие кремовые поверхности `#f3ebe4`, золотой акцент `#b0903d`, коричневые основные действия, Cormorant для крупных заголовков и Montserrat для интерфейсного текста. Заголовки выводятся в обычном регистре без искусственного letter-spacing.

## Архитектура

Основной слой — отдельный условно подключаемый файл `assets/css/woocommerce-order-ui.css`. Он оформляет нативную семантическую разметку WooCommerce и переиспользуется на всех перечисленных экранах.

Шаблоны переопределяются только там, где CSS не способен исправить структуру. Для блока данных клиента используется один точечный override: адрес доставки не выводится, если его действительно нет, вместо карточки со значением «Н/Д». Остальные данные и хуки WooCommerce сохраняются.

## Компоненты

- подтверждение заказа — спокойная верхняя карточка с сообщением и основными параметрами;
- метаданные заказа — адаптивная сетка компактных элементов;
- таблица заказа — лёгкая карточка с разделителями и выраженным итогом;
- адреса — равноправные карточки с понятными заголовками, без повторов и пустых секций;
- список заказов — та же табличная система со статусами и компактными кнопками;
- сообщения WooCommerce — существующий золотой акцент и нейтральный фон;
- кнопки — существующая овальная коричнево-золотая система темы.

## Адаптивность

На ширине до 760 px таблицы переходят в вертикальные строки по `data-title`, метаданные заказа становятся одной колонкой, адресные карточки складываются друг под другом, а кнопки получают удобную область касания. Горизонтальная прокрутка не допускается.

## Доступность

Сохраняются таблицы, заголовки и `address` из WooCommerce. Контраст берётся из уже используемой палитры темы. Фокус кнопок и ссылок остаётся видимым. Анимации не обязательны; при `prefers-reduced-motion` интерфейс полностью статичен.

## Проверка

- автоматическая проверка наличия условного подключения стилей и минимального template override;
- Playwright-проверка desktop/mobile на контролируемой разметке WooCommerce;
- PHP lint переопределённого шаблона и изменённого загрузчика;
- существующие тесты корзины, checkout и личного кабинета.
