# Редизайн админки Theobroma 1C

Страница интеграции получает ограниченный по ширине рабочий экран в стиле WordPress/WooCommerce: статус и URL обмена в шапке, две карточки подключения и диагностики, отдельная история обменов и сворачиваемый блок сопоставления Ozon. Функции обмена и формат сохранённых настроек не меняются.

Ozon описывается как необязательный импорт идентификаторов товаров. Он записывает Ozon Product ID, Ozon SKU, EAN и артикул клиента в товары WooCommerce, но не импортирует заказы Ozon и не подключается к API Ozon. Предпросмотр обязателен, неоднозначные сопоставления выбираются вручную.

Стили загружаются только на странице `woocommerce_page_theobroma-1c`, используют локальный CSS без внешних зависимостей, сохраняют стандартные WordPress controls, видимый focus и адаптивную компоновку. URL доступен как обычное поле для удобного ручного копирования без обязательного JavaScript.
