# Плавные карточки и переключение каталога без перезагрузки

## Цель

Сделать увеличение изображения товара плавным и переключать группы каталога без полной навигации документа, сохранив рабочие URL и поддержку кнопок браузера «Назад»/«Вперёд».

## Решение

- Для изображения карточки каталога явно задать transition свойства `transform` длительностью 650 мс с мягкой cubic-bezier кривой. Текущий масштаб `1.04` сохранить.
- Добавить отдельный скрипт каталога, подключаемый только на страницах магазина и категорий товаров.
- Перехватывать обычные клики по `.catalog-filters a`, загружать целевой URL через `fetch`, разбирать HTML через `DOMParser` и заменять содержимое существующего `.catalog-page`.
- После успешной замены обновлять URL через `history.pushState`; на `popstate` повторно загружать каталог без добавления новой записи истории.
- Оставить ссылки полноценными: без JavaScript и при ошибке загрузки выполняется обычная навигация.
- При параллельных переключениях отменять предыдущий запрос и отражать занятость через `aria-busy`.

## Границы

Не меняются серверная фильтрация WooCommerce, карточки товаров, логика корзины и размеры сетки. Изменение ограничено шаблоном подключения ассетов, новым скриптом каталога, стилем изображения и регрессионным тестом.

## Проверка

Playwright-тест должен доказать два наблюдаемых поведения: в начале hover изображение находится в промежуточном масштабе и приходит к `1.04` плавно; клик по фильтру не создаёт навигацию документа, но заменяет товары, активный фильтр и URL. Отдельно проверяется `popstate`.
