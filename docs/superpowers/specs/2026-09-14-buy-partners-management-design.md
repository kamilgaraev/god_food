# Управление бутиками и партнёрами в разделе «Где купить»

## Цель

Перенести карточки бутиков и партнёров из шаблона в управляемые записи WordPress. Контент-менеджер должен добавлять, редактировать, скрывать и менять порядок карточек через отдельный раздел админки, сохраняя текущие вкладки «Бутики» и «Вся Россия» на сайте.

## Архитектура

Создаются два публичных типа записей: `theobroma_boutique` и `theobroma_partner`. Оба типа доступны только администраторам и редакторам контента через единый верхнеуровневый пункт меню «Где купить». Для каждого типа используется стандартный редактор WordPress с собственной метабокс-панелью полей; публикация управляется статусом записи, а порядок — `menu_order`.

В админке:

- «Бутики» показывает список с миниатюрой, названием, адресом, графиком и статусом публикации.
- «Партнёры» показывает список с логотипом, названием, городом и статусом публикации.
- Кнопки «Добавить бутик» и «Добавить партнёра» ведут на отдельные формы с понятными подписями и подсказками.
- Для изображения используется медиатека WordPress и превью; для ссылки карты/магазина — URL-поле с проверкой безопасной схемы.
- В списках сохраняется стандартная массовая публикация/снятие с публикации, а порядок задаётся числом сортировки в форме записи.

Поля бутика: название, фотография, адрес, часы работы, ссылка «Как добраться», порядок вывода.

Поля партнёра: название, логотип, город, ссылка на магазин или сайт, порядок вывода.

## Вывод на сайте

Шаблон страницы «Где купить» получает опубликованные записи через запросы с `post_status=publish`, сортировкой по `menu_order` и затем по названию. Вкладка «Бутики» выводит карточки бутиков, вкладка «Вся Россия» — карточки партнёров. При отсутствии записей выводится спокойное сообщение вместо пустого пространства. Текущая анимация перехода между вкладками и существующие адаптивные стили сохраняются.

Старые жёстко зашитые карточки переносятся в записи при миграции один раз. Повторный запуск миграции не создаёт дубликаты: записи помечаются стабильным ключом исходной карточки.

## Безопасность и ошибки

Сохранение метаполей доступно только пользователям с правом редактирования соответствующего типа записи и защищено nonce. Текстовые поля проходят санитаризацию, URL — `esc_url_raw` с разрешёнными `http` и `https`, изображения принимаются только как attachment ID. Удалённое или отсутствующее изображение не ломает карточку: используется нейтральный фон с названием.

## Проверка

- PHP lint для новых классов и шаблонов.
- Проверка админского списка и формы с опубликованной, черновой и пустой записью.
- Проверка вывода обеих вкладок и переходов между ними на 320, 768 и 1440 px в Chromium и WebKit.
- Проверка, что старые хардкод-карточки не появляются после миграции и что порядок `menu_order` соблюдается.
